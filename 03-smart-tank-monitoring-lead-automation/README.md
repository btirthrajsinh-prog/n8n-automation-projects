# Smart Tank Monitoring Lead Automation

## Project Overview

An automation workflow for processing Smart Tank Monitoring System
lead inquiries and performing scheduled WhatsApp follow-up.

## Workflow

Meta Lead Inquiry
        ↓
Google Sheets
        ↓
Daily 10:00 AM Automation
        ↓
Lead Processing
        ↓
WhatsApp Template Message
        ↓
Smart Tank Monitoring Information / Brochure
        ↓
Lead Reply
        ↓
AI-Assisted Response

## Components

- Meta Leads
- Google Sheets
- n8n
- Green-API WhatsApp API
- WhatsApp
- AI-assisted responses

## Automation

Lead information was maintained in Google Sheets and processed
through a scheduled automation at 10:00 AM.

Relevant leads received a predefined WhatsApp template message
related to the Smart Tank Monitoring System.

## AI-Assisted Responses

The workflow also included an AI-assisted mechanism for handling
follow-up questions and continuing conversations with leads.

## Purpose

The automation was designed to reduce manual lead follow-up and
provide faster communication with Smart Tank Monitoring System
inquiries.
